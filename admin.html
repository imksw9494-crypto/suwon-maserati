Setup

매물 저장소가 아직 연결되지 않았습니다.

아래 순서로 한 번만 준비하면, 이 화면에서 로그인해 매물을 바로 올릴 수 있습니다.

  1. Supabase 가입 후 프로젝트 만들기supabase.com 에서 무료로 가입하고 새 프로젝트를 하나 만듭니다. 지역은 Seoul 을 고르면 됩니다.
  2. 설정 파일 실행하기함께 받은 supabase-setup.sql 맨 아래 이메일을 직원 이메일로 바꾼 뒤, SQL Editor 에 붙여 넣고 Run 을 누릅니다.
  3. 직원 계정 만들기Authentication → Users 에서 같은 이메일로 사용자를 추가하고 비밀번호를 정합니다.
  4. 연결 정보 넣기프로젝트 주소와 Publishable key 를 config.js 에 넣고 사이트를 다시 올립니다.
